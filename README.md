## What it does

Pomodoro runs work/break/long-break sessions with a circular countdown, configurable durations, and a vibration + beep when each session ends.

## Features

- Work / break / long break modes with circular progress ring
- Start, pause, reset and skip controls
- Custom durations - work, break, long break, sessions before long break
- Vibration + double beep when a session ends
- Completed session counter
- System / dark / light theme
- Offline-first - works without internet
- Lightweight, no ads

## Get an APK (`for devs`)

1. Fork / clone this repo.
2. Push to GitHub → the **Build APK** workflow runs automatically.
3. Go to **Actions** → latest run → download the **Pomodoro** artifact.
4. Install the APK on your Android device.

> Make sure **Play Protect is turned off** before installing.
